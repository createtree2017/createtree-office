# PDF 보고서 기능 구현 완료 보고서

> 작성일: 2026-03-18

---

## 1. 개요

텔레그램 내장 브라우저 호환성 문제로 인해 기존 링크 방식의 보고서 전달이 불가능했던 문제를 해결하기 위해, **PDF 보고서 생성 및 텔레그램 파일 첨부 발송** 기능을 구현했습니다.

### 해결된 문제
- 텔레그램 메시지 내 링크가 텔레그램 내장 브라우저에서 열리지 않는 문제
- 사용자가 보고서를 확인하기 위해 별도로 사이트 접속이 필요했던 불편함

### 적용된 방식
- 모니터링 완료 시 **PDF 파일로 변환하여 텔레그램 채팅에 직접 첨부**
- 사이트 내 보고서 모달에 **PDF 다운로드 버튼** 추가

## 2. 신규 의존성

```bash
# 루트 디렉토리에서 실행
npm install form-data html2pdf.js
```

| 패키지 | 버전 | 용도 |
|--------|------|------|
| `form-data` | ^4.x | 텔레그램 `sendDocument` API multipart/form-data 전송 |
| `html2pdf.js` | ^0.10.x | 기존 견적서/계약서 페이지에서 사용 중이었으나 미설치 상태 해소 |

> **참고**: Playwright는 기존에 이미 설치되어 있으므로 추가 설치 불필요

## 3. 변경 파일 목록

### 3.1 서버 (4개 파일)

#### `server/src/services/monitoring/reportGenerator.ts`
- **추가**: `generatePdf()` 메서드
- Playwright로 HTML 보고서를 렌더링 후 A4 PDF로 변환
- `printBackground: true`로 색상/그라데이션 유지

#### `server/src/routes/monitoring.ts`
- **추가**: `GET /api/monitoring/results/:id/pdf`
- 인증 토큰 필수 (`authenticateToken`)
- PDF Buffer를 `application/pdf`로 응답

#### `server/src/services/notification/telegramService.ts`
- **추가**: `sendDocument()` — PDF Buffer를 텔레그램 파일로 전송
- **수정**: `sendMonitoringAlert()` — `pdfBuffer` 파라미터 추가
  - PDF 있으면 → 파일 첨부 발송 (HTML caption)
  - PDF 없으면 → 기존 텍스트 메시지 (안전한 fallback)

#### `server/src/services/monitoring/monitoringService.ts`
- **수정**: Step 5 텔레그램 알림 발송 부분
  - PDF 생성 후 `sendMonitoringAlert()`에 Buffer 전달
  - PDF 생성 실패 시 텍스트 알림으로 자동 대체

### 3.2 프론트엔드 (1개 파일)

#### `client/src/pages/MonitoringPage.tsx`
- **추가**: `downloadPdf()` 함수 — `/api/monitoring/results/:id/pdf` 호출 후 다운로드

## 4. 기능 흐름

### 4.1 텔레그램 PDF 첨부 발송
```
모니터링 완료
  → reportGenerator.generatePdf() 호출
  → Playwright로 HTML 렌더링 → PDF Buffer 생성
  → telegramService.sendDocument()로 파일 첨부 발송
  → 사용자: 텔레그램에서 PDF 탭 → 기기 PDF 뷰어로 바로 열람
```

### 4.2 사이트 PDF 다운로드
```
모니터링 결과 목록 → 결과 클릭 → 상세 모달 → "PDF" 버튼 클릭
  → GET /api/monitoring/results/:id/pdf
  → Playwright PDF 생성 → 브라우저 다운로드
```

## 5. 다른 환경 배포 시 확인사항

### 5.1 필수 환경
- **Node.js 18+**
- **Playwright + Chromium**: `npx playwright install chromium`
- Railway/Docker 사용 시 Dockerfile에 Chromium 관련 시스템 의존성 포함 필요

### 5.2 환경 변수
| 변수 | 용도 | 예시 |
|------|------|------|
| `TELEGRAM_BOT_TOKEN` | 텔레그램 Bot API 토큰 | `123456:ABC-DEF...` |
| `APP_URL` | 사이트 기본 URL (현재 미사용으로 변경됨) | `https://office.createtree.co.kr` |

### 5.3 설치 순서
```bash
# 1. 의존성 설치
npm install

# 2. Playwright 브라우저 설치 (서버 환경에서 필수)
npx playwright install chromium

# 3. 환경 변수 확인
# server/.env에 TELEGRAM_BOT_TOKEN 설정 확인

# 4. 서버 실행
npm run dev
```

## 6. 테스트 방법

### 사이트 PDF 다운로드
1. `/monitoring` → 결과 목록 → 완료된 결과 클릭
2. 상세 모달에서 빨간색 "PDF" 버튼 클릭 → PDF 다운로드 확인

### 텔레그램 PDF 첨부
1. 알림 설정된 템플릿으로 모니터링 실행
2. 완료 후 텔레그램 채팅에 PDF 파일 첨부 확인
3. PDF 탭하여 내용 및 링크 동작 확인
