# 견적서 시스템 — 완료 보고서

## 개요

거래처별 서비스 견적서를 디지털로 생성·관리하는 시스템. Phase 1 서비스 상품 마스터 데이터 기반 동작.

## 핵심 기능

- **4단계 위자드**: 거래처/기본 → 서비스 선택 → 가격/옵션 → 최종 확인
- **자동 계산**: 소계/할인/공급가액/부가세(10%)/합계(VAT포함)/월청구 자동 산출
- **가격 시점 보존**: 견적 생성 시점 단가 영구 보존
- **자동 채번**: `QT-YYYYMMDD-NNN` 형식
- **계약 기간**: 단건(1회성) / 3·6·12·24개월 선택
- **월정액 수량 자동설정**: 계약기간 선택 시 월정액 항목 수량 자동 반영
- **할인 적용**: 6개월/12개월 할인 정책 관리자 선택 적용

## 버그 수정 이력

| 항목               | 원인                       | 해결                                             |
| ------------------ | -------------------------- | ------------------------------------------------ |
| 편집 버튼 미작동   | 목록 데이터에 items 미포함 | API 상세조회(GET /:id)로 변경                    |
| 단건 견적 불가     | 계약기간 옵션에 1회성 없음 | '단건(1회성)' 옵션 추가 (contractMonths=0)       |
| 월정액 수량 미반영 | 모든 항목 수량 1 고정      | 월정액 서비스는 계약기간을 수량으로 자동 설정    |
| 부가세 미표시      | 부가세 없이 총액만 표시    | 공급가액 → 부가세(10%) → 합계(VAT포함) 구조 추가 |
