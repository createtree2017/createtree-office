# 계약서 시스템 — 완료 보고서

## 개요
견적서(수락)를 계약서로 변환하고, 계약 상태를 관리하는 시스템.
기존 `clients` 테이블의 계약 관련 필드(contractStartDate, contractEndDate, contractEndedAt)와 자동 연동.

## 핵심 기능
- **견적서→계약서 원클릭 변환**: 견적 수락 → "계약서 생성" 버튼 → 금액/항목 자동 복사
- **계약 상태 흐름**: 초안 → 서명완료 → 활성 → 만료/해지
- **clients 자동 연동**: 활성화 시 계약시작일/종료일 자동 업데이트, 해지 시 contractEndedAt 설정
- **자동 종료일 계산**: 시작일 입력 시 계약개월 기반 종료일 자동 계산
- **자동 채번**: CT-YYYYMMDD-NNN 형식
- **부가세(10%) 표시**: 공급가액 → 부가세 → 합계(VAT포함)
