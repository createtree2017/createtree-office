# 서비스 상품 마스터 시스템 — 완료 보고서

## 개요

사업운영관리 시스템의 핵심 기반인 **서비스 상품 마스터**를 성공적으로 개발 완료했습니다.
창조트리기획의 7가지 서비스를 동적 데이터 구조로 정확히 표현하는 DB + API + UI를 구현했습니다.

## 핵심 설계 원칙

1. **선택형 자동화** — 관리자가 선택하면 자동 계산, 강제 자동화 없음
2. **과금 유형 다양성** — 월정액/건당/일회성/견적기반 모두 지원
3. **동적 구조** — 하드코딩 없이 DB 기반 유연한 관리
4. **가격 이력 보존** — 견적 시점 가격 보존 설계

## 개발 완료 항목

### DB 스키마 (server/src/db/schema.ts)
- **Enum 3개**: `billing_type`, `price_unit`, `item_category`
- **테이블 5개**: `services`, `service_tiers`, `service_items`, `service_item_prices`, `contract_discount_policies`
- 등급별 가격 매트릭스 구조 (tierId=null → 전 등급 공통 단가)

### 공유 타입 (shared/types.ts)
- 서비스 관련 TypeScript 인터페이스 10개 추가

### 백엔드 API (server/src/routes/services.ts)
| Method | Endpoint | 설명 |
|--------|----------|------|
| GET | /api/services | 전체 서비스 목록 (중첩 데이터 포함) |
| GET | /api/services/:id | 단일 서비스 상세 |
| POST | /api/services | 서비스 생성 (tiers, items, prices 동시) |
| PUT | /api/services/:id | 서비스 수정 (전체 동기화) |
| DELETE | /api/services/:id | 서비스 비활성화 (soft delete) |
| GET | /api/services/discount-policies | 할인 정책 조회 |
| PUT | /api/services/discount-policies | 할인 정책 일괄 수정 |

### 프론트엔드 UI (client/src/pages/ServiceProductsPage.tsx)
- **목록 모드**: 서비스 카드 그리드 (과금유형 뱃지, 등급/항목/가격 요약)
- **편집 모드**: 기본정보 + 등급관리 + 항목관리 + 가격매트릭스
- **토글 스위치**: 활성/비활성 상태를 직관적 스위치 UI로 표시 (저장 버튼 옆)
- **할인 정책 패널**: 계약 기간별 할인 정책 관리

### 시드 데이터 (server/src/scripts/seedServices.ts)
- 7개 서비스 등록 (행사, 서포터즈, AI문화센터, AI오피스, 홈페이지, AI자동화, 인테리어)
- 2개 할인 정책 (6개월 5%, 12개월 10%)

## 버그 수정 이력
| 항목 | 원인 | 해결 |
|------|------|------|
| 할인정책 저장 미작동 | Express 라우트 순서 문제 (/:id가 /discount-policies보다 앞에 정의) | 할인정책 라우트를 /:id보다 위로 이동 |
| 활성 상태 UI 가시성 | 체크박스가 눈에 안 띔 | CSS 토글 스위치로 변경, 저장 버튼 옆으로 이동 |
