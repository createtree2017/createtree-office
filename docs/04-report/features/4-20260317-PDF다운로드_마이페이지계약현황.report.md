# Phase 4: PDF 다운로드 + 마이페이지 계약현황 — 완료 보고서

> 작성일: 2026-03-17

---

## 개요
견적서/계약서를 PDF로 다운로드하는 기능과, 담당 회원이 마이페이지에서 자신의 거래처 견적서/계약서 현황을 확인할 수 있는 기능을 개발.

---

## 핵심 기능

### 1. PDF 다운로드
- **견적서 상세뷰**: `📥 PDF` 버튼 → `QT-YYYYMMDD-NNN.pdf` 파일명으로 다운로드
- **계약서 상세뷰**: `📥 PDF` 버튼 → `CT-YYYYMMDD-NNN.pdf` 파일명으로 다운로드
- **라이브러리**: `html2pdf.js` (클라이언트 사이드 렌더링)
- **PDF 옵션**: A4 세로, 2x 고화질 캔버스, 여백 10mm

### 2. 마이페이지 계약 & 견적 현황
- **위치**: 회원정보 카드 ↔ 비밀번호 변경 사이 (새 섹션)
- **표시 조건**: 사용자에게 `clientId`가 연결되어 있을 때만 표시
- **구성 요소**:
  - 🟢 **현재 활성 계약 요약 카드**: 계약명, 계약번호, 기간, 월 청구액 (VAT 포함)
  - 📄 **견적서 N건 버튼**: 클릭 시 펼침/접힘으로 견적서 리스트 표시
  - 📋 **계약서 N건 버튼**: 클릭 시 펼침/접힘으로 계약서 리스트 표시
- **리스트 항목 정보**: 상태 배지, 문서번호, 제목, 날짜, 합계금액(VAT포함), 월 청구액

## API 추가

### `GET /api/contracts/my/status`
| 항목 | 내용 |
|------|------|
| 인증 | JWT 토큰 (모든 권한) |
| 동작 | 로그인 사용자의 `clientId` 조회 → 해당 거래처의 견적서/계약서 반환 |
| 응답 | `{ clientName, quotations[], contracts[] }` |

> ⚠️ Express 라우트 순서 주의: `/my/status`는 `/:id` 와일드카드 라우트보다 **앞에** 배치해야 정상 동작

## 기술 상세

### PDF 생성 방식
```
html2pdf.js (클라이언트 사이드)
├── html2canvas로 DOM → Canvas 렌더링 (scale: 2)
├── jsPDF로 Canvas → PDF 변환 (A4, portrait)
└── 자동 다운로드 (.save())
```

### 마이페이지 UI 구조
```
마이페이지
├── 👤 회원정보 (기존)
├── 📋 계약 & 견적 현황 ← 신규
│   ├── 활성 계약 요약 카드 (emerald 테마)
│   ├── [견적서 N건] 토글 → 리스트
│   └── [계약서 N건] 토글 → 리스트
├── 🔒 비밀번호 변경 (기존)
└── 🚪 로그아웃 (기존)
```
