# 클라이언트 전체 lint 정리 인수인계

## 작업 배경

- 시장조사 시스템 구현 후 `npm run lint --prefix client` 전체 앱 lint가 기존 unrelated 파일의 미사용 import/state, hook dependency, fast refresh 경고로 실패했다.
- 배포 안정성과 이후 코드 수정 안전성을 위해 클라이언트 전체 lint를 통과 상태로 정리했다.
- 전체 시장조사는 실행하지 않았다.

## 변경 내용

- `client/src/contexts/ModalContext.tsx`
  - `useModal` hook을 별도 파일로 분리해 fast refresh 경고를 제거했다.
  - 신규 파일:
    - `client/src/contexts/modalContextCore.ts`
    - `client/src/contexts/useModal.ts`
  - 기존 `useModal` 사용처 import를 새 hook 파일로 변경했다.

- `client/src/components/*`
  - `CreateManualModal.tsx`: 미사용 `Smile` import 제거
  - `ManualEditor.tsx`: `fetchGoogleForms`를 `useCallback`으로 안정화하고 `useEffect` dependency를 보정
  - Modal hook import 경로 변경:
    - `CreateManualModal.tsx`
    - `CreateTaskModal.tsx`
    - `ExpandedColumnModal.tsx`
    - `TaskDetailModal.tsx`

- `client/src/hooks/useTaskResponse.ts`
  - 미사용 `apiFetch` import 제거

- `client/src/pages/*`
  - `AdminPage.tsx`: 미사용 interface 제거, `servicesMap`을 `const`로 변경
  - `ContractsPage.tsx`: 자동 상세 열기 effect dependency 보정, 미사용 `vatAmount` 제거
  - `DrivePage.tsx`: 미사용 `toast` 제거, 재할당 없는 변수 `const` 처리
  - `ManualsPage.tsx`: 상세 조회 함수 `useCallback` 보정, 미사용 drag 변수/계산 제거
  - `MonitoringPage.tsx`: 미사용 import/state/function 제거
  - `SalesLeadsPage.tsx`: 미사용 상태 라벨 함수 제거
  - `ServiceProductsPage.tsx`: 미사용 import/상수/함수 제거
  - `TaskResponsePage.tsx`: 미사용 원본 응답 state 제거, `no-case-declarations` 보정
  - `TasksPage.tsx`: 미사용 import/drag 변수/이벤트 인자 제거
  - `TemplatesPage.tsx`: 미사용 import 제거

## 검증 결과

- `npm run lint --prefix client`: 통과
- `npm run build --prefix client`: 통과
- `npm run build --prefix server`: 통과
- `npm run skills:check`: 통과

## 운영 참고

- `npm run build --prefix client` 실행 시 Vite의 500kB 이상 chunk size 경고는 표시되지만 빌드는 성공한다.
- 이번 작업은 lint 정리 범위이며 시장조사 수집 로직과 DB 스키마는 변경하지 않았다.
- 전체 시장조사는 실행하지 않았다.
