# 시장조사 규모 필터 추가 인수인계

## 변경 파일

- `client/src/hooks/useMarketResearch.ts`
- `client/src/pages/MarketResearchPage.tsx`
- `server/src/routes/marketResearch.ts`

## 핵심 변경 내용

- 시장조사 결과 화면의 조사 필터에 규모 필터를 추가했다.
- 규모 필터는 DB의 `buildingScale` 값을 기준으로 API 목록, 요약, ID 조회, 엑셀 다운로드에 동일하게 적용된다.
- 필터 옵션은 병원 영업에서 쓰기 쉬운 그룹으로 구성했다.
  - 전체
  - 의원
  - 병원
  - 종합병원
  - 상급종합
  - 요양병원
  - 한방병원
  - 보건기관
  - 기타
  - 미입력
- `보건기관`은 `보건소`, `보건지소`, `보건의료원`을 묶는다.
- `기타`는 위 그룹에 포함되지 않는 값이다. 산후조리원 CSV에서 들어온 `건물 6층 규모` 같은 층수 값도 여기에 포함된다.

## 확인한 현재 규모 값

- 주요 HIRA 종별: `의원`, `병원`, `종합병원`, `상급종합`, `요양병원`, `한방병원`, `정신병원`, `보건소`, `보건지소`, `보건의료원`
- 산후조리원/기타 원본: `건물 N층 규모`, `단독건물 여부 확인 필요`, `일부층 사용, 층수 확인 필요`, 미입력 등

## 검증 결과

- `npm run build --prefix server`: 통과
