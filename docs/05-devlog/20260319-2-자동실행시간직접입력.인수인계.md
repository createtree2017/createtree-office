# 인수인계: 모니터링 템플릿 자동 실행 시간 직접 입력 변경

- **작성일**: 2026-03-19
- **작업자**: AI (Antigravity)
- **작업 단위**: 모니터링 템플릿 – 자동 실행 시간 선택 UI 변경

---

## 1. 변경 목적

기존 자동 실행 시간 선택이 **1시간 간격 드롭다운**(00:00 ~ 23:00)으로 되어 있어 5분, 30분 등 세밀한 시간 지정이 불가능했음.
→ **시(0~23)와 분(0~59)을 직접 숫자로 입력**할 수 있도록 UI 변경.

## 3. 핵심 변경 내용

### 3-1. `MonitoringPage.tsx` – TemplateFormModal

#### (a) `scheduleMinute` 상태 추가 (기존 `scheduleHour` 옆)
- cron 파싱 시 분(`parts[0]`)도 추출하여 초기값 설정
- 기본값: `0`

#### (b) cron 표현식 생성 변경
```diff
- `0 ${scheduleHour} * * *`
+ `${scheduleMinute} ${scheduleHour} * * *`
```

#### (c) UI 변경 (자동 실행 시간 영역)
- **기존**: `<select>` 드롭다운 (00:00 ~ 23:00 + 2분마다 테스트)
- **변경**: `<input type="number">` 2개 (시 : 분) + 테스트 모드 체크박스 분리
  - 시: min=0, max=23
  - 분: min=0, max=59
  - 체크박스: `⚡ 2분마다 실행 (테스트용)` — 체크 시 시/분 입력 비활성화

#### (d) 안내 텍스트 업데이트
```diff
- 매일 09:00에 자동 실행됩니다
+ 매일 09:30에 자동 실행됩니다  (분까지 표시)
```

### 3-2. 카드 목록 시간 표시 (MonitoringPage + TemplatesPage)
- **기존**: `자동: 0 9 * * *` (원시 cron 그대로)
- **변경**: `자동: 09:00` 또는 `자동: ⚡ 2분마다` (사람이 읽기 쉬운 형태)
