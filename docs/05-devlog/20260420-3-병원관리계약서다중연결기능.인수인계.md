# 인수인계: 병원 관리 화면의 계약서 다중 연결 (견적서 연결 기능 삭제)

## 1. 작업 개요
- **날짜**: 2026-04-20
- **담당**: AI Agent
- **작업명**: 병원(거래처) 관리 화면에서 불필요해진 "견적서 수동 연결" 버튼을 제거하고, 여러 개의 활성(Active) 계약서를 자동으로 감지하여 팝업(모달) 형태로 다중 표시하도록 개편.

## 2. 변경 파일 목록
1. `server/src/routes/client.ts` (수정)
   - `GET /api/clients` 조회 시 `contracts` 테이블을 조회하여 해당 `clientId`를 가진 상태가 'active'인 모든 계약서 목록(`activeContracts`)을 배열 형태로 포함하여 반환하도록 로직 추가.
2. `client/src/pages/AdminPage.tsx` (수정)
   - `Client` 인터페이스에 `activeContracts` 배열 타입 추가.
   - 불필요한 견적서 연결 버튼 및 기존 1:1 수동 연결(linkModal) 관련 로직/UI 삭제.
   - 계약서 관리 버튼 클릭 시 `activeContracts` 배열 길이에 따라 "진행 중: N건" 표시.
   - 버튼 클릭 시 해당 거래처에 귀속된 다수의 활성 계약을 리스트로 볼 수 있는 새로운 팝업 모달(`activeContractsModalClientId`) UI 구현.
   - 모달 하단에 해당 병원으로 필터링된 계약서 페이지(`?clientId=...`)로 바로 이동하여 새 계약을 추가할 수 있는 버튼 연동.

## 3. 핵심 변경 내용
### 3.1. 수동 연결에서 자동 연결로의 패러다임 전환
- 기존에는 관리자가 일일이 "연결" 버튼을 눌러야만 계약서 1개가 거래처 카드에 연동되는 구조였습니다. (이로 인해 계약 해지나 삭제 후에도 "연결됨" 표시가 남는 유령 데이터 현상이 발생했습니다.)
- 개편 후에는 백엔드에서 실시간으로 해당 병원의 "활성(active) 상태인 계약서"를 쿼리하여 거래처 데이터에 배열로 담아줍니다. 즉, 계약서 페이지에서 새 계약을 `active` 상태로 만들면 병원 카드에 자동으로 연동되고, 해지(terminate)하면 자동으로 빠집니다.

### 3.2. 단건 계약 한계 극복 (마케팅 외 별도 계약 지원)
- 이제 하나의 병원에 [마케팅 정기 계약], [홈페이지 제작 단건 계약], [인테리어 계약] 등 여러 건의 계약이 동시에 존재하더라도 한눈에 확인하고 접근할 수 있습니다.

## 4. 동작 확인 상태
- ✅ 백엔드 API: `activeContracts` 자동 패치 및 리스폰스 병합 확인
- ✅ 프론트엔드: 견적서 연결 뱃지 삭제 및 다중 계약 모달 노출 확인
- ✅ UI/UX: 팝업을 통한 바로가기 링크(`?clientId=...`) 연동 확인

## 5. 다음 작업 참고사항
- 데이터베이스(`schema.ts`)의 `linkedQuotationId` 및 `linkedContractId` 컬럼은 하위 호환성을 위해 당장 삭제하지 않고 유지해 두었습니다. 추후 대대적인 마이그레이션이 있을 때 완전히 드랍(drop)해도 무방합니다.
- 현재 병원 관리 탭에서 계약서 버튼을 눌러 새로운 "계약 목록" 팝업이 잘 작동하는지 확인 바랍니다.

## 6. 추가 수정사항 (2026-04-20)
- **작업명**: 병원 카드 메인에 표시되던 "계약 날짜" 제거
- **이유**: 병원 카드 메인에 표시되던 날짜는 가장 최근에 활성화된 단일 계약의 날짜(`contractStartDate`)를 보여주고 있었습니다. 다중 계약 시스템으로 개편됨에 따라 1개의 대표 날짜만 노출하는 것이 혼란을 줄 수 있다고 판단하여, 개별 계약 날짜는 **[계약서 팝업 모달]** 내부에서 확인하도록 유도하고 카드 메인에서는 날짜 표시 영역을 완전히 제거했습니다.
- **변경 내용**: `client/src/pages/AdminPage.tsx`에서 병원명 하단에 렌더링되던 `contractStartDate ~ contractEndDate` 텍스트 블록 삭제.
