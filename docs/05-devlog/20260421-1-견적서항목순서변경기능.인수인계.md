# 20260421-1-견적서항목순서변경기능.인수인계

## 1. 작업 개요
- **작업일**: 2026-04-21
- **분류**: Minor Change
- **목적**: 견적서 작성 화면에서 견적서 항목의 순서를 위/아래로 변경할 수 있는 기능 추가
- **요청 사항**: 견적서 항목 순서 변경 기능 추가 요청 반영 (위/아래 이동 버튼 방식)

## 2. 변경 사항
- **UI 업데이트**: `QuotationsPage.tsx` 내의 견적서 항목 테이블 우측 끝 열(관리 열)에 위/아래 화살표 버튼(`ArrowUp`, `ArrowDown`) 추가
- **순서 변경 로직 구현**:
  - `moveRowUp`: 선택된 항목과 그 위 항목의 배열상 위치를 맞바꾸는 함수 추가
  - `moveRowDown`: 선택된 항목과 그 아래 항목의 배열상 위치를 맞바꾸는 함수 추가
- **저장 시스템 연동**: 기존 백엔드 저장 로직에서 화면 배열의 index를 `sortOrder`로 저장하도록 설계되어 있어, 별도의 백엔드 코드 수정 없이 프론트엔드 기능 추가만으로 데이터베이스와 정상 연동됨.

## 3. 변경 파일 목록
- `client/src/pages/QuotationsPage.tsx` (수정)
  - `ArrowUp`, `ArrowDown` 아이콘(lucide-react) 임포트 추가
  - `moveRowUp`, `moveRowDown` 상태 변경 함수 추가
  - 테이블 헤더 명칭 변경 ("순서/관리") 및 버튼 렌더링 로직 추가

## 4. 동작 확인 상태
- ✅ **견적서 항목 순서 변경**: 위/아래 화살표 클릭 시 항목 순서 즉시 변경
- ✅ **이동 제한**: 첫 번째 항목의 '위로' 버튼 비활성화, 마지막 항목의 '아래로' 버튼 비활성화 정상 적용

## 5. 다음 작업 참고사항
- `quotation_items` 테이블의 `sort_order` 필드가 견적서 항목의 고유 순서를 저장하는 데 완벽히 작동하고 있습니다. 나중에 계약서 쪽에서도 항목 순서 조작이 필요하다면 비슷한 패턴으로 구현하면 됩니다.
