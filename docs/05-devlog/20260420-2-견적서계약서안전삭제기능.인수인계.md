# 인수인계: 견적서 및 계약서 안전 삭제 기능 추가

## 1. 작업 개요
- **날짜**: 2026-04-20
- **담당**: AI Agent
- **작업명**: 거래처 데이터와 직결된 완료본(계약 개시본)을 보호하고, 진행 중인 문서(초안 등)만 삭제할 수 있도록 휴지통 기능 구현 및 안전장치 적용.

## 2. 변경 파일 목록
1. `server/src/routes/quotations.ts` (수정)
   - `DELETE /:id` 엔드포인트에 `status === 'approved'`(승인됨) 상태인 경우 삭제를 거부하는 방어 로직 추가.
2. `server/src/routes/contracts.ts` (수정)
   - `DELETE /:id` 엔드포인트 신규 추가. 
   - `active`(활성), `terminated`(해지), `expired`(만료) 상태인 경우 삭제를 거부하는 방어 로직 적용.
3. `client/src/pages/QuotationsPage.tsx` (수정)
   - 견적서 목록에서 승인(approved) 상태인 경우 삭제(휴지통) 버튼이 노출되지 않도록 조건부 렌더링 수정.
4. `client/src/pages/ContractsPage.tsx` (수정)
   - 계약서 목록 테이블 우측에 "관리" 컬럼 추가 및 삭제(휴지통) 아이콘 배치.
   - 계약서 상세 보기 창 우측 상단에도 [삭제] 버튼 배치.
   - 삭제 기능은 `draft`(초안) 및 `signed`(서명완료) 상태일 때만 보이도록 설정.

## 3. 핵심 변경 내용
### 3.1. 완료본 보호 (백엔드 안전장치)
- 시스템 아키텍처 상 계약서가 "활성(active)" 상태가 되면 거래처 테이블의 계약 시작일, 만료일 등의 라이프사이클이 연동됩니다.
- 따라서 이미 승인되었거나 실계약에 들어간 문서가 물리적으로 삭제되어 거래처 데이터 무결성이 깨지는 것을 백엔드 API 레벨에서 원천 차단했습니다.

### 3.2. 휴지통 접근성 강화 (프론트엔드)
- 실수로 잘못 작성했거나 불필요해진 "초안" 계약서들을 쉽게 지울 수 있도록, 계약관리 페이지에 즉각적인 삭제 인터페이스를 마련했습니다.

## 4. 동작 확인 상태
- ✅ 백엔드 API 방어 로직 
- ✅ 프론트엔드 조건부 렌더링 (진행 중 문서만 삭제 허용)
- ✅ Contract 삭제 API 엔드포인트 연동

## 5. 다음 작업 참고사항
- 현재 브라우저에서 계약서(초안) 목록이나 견적서(초안) 목록에서 [휴지통 아이콘]을 클릭해 정상적으로 지워지는지 확인하실 수 있습니다.
- "활성" 상태인 계약서는 삭제 버튼이 나타나지 않으며, 필요 시 [상태 변경] 버튼(예: 계약 해지)만 사용할 수 있습니다.
