# 시장조사 배포서버 실행 차단 인수인계

## 작업 배경

- 시장조사는 관리자 로컬 PC에서 실행하고, 결과는 Railway PostgreSQL에 저장해 로컬/배포 사이트 어디서든 조회하는 운영 방식으로 결정했다.
- 모니터링, Drive, 메일 등 다른 기능도 API 키를 사용하므로 Railway Variables에서 공용 키를 제거하는 방식은 사용할 수 없다.
- 따라서 시장조사 실행 API만 별도 env 플래그로 차단한다.

## 변경 내용

- `server/src/routes/marketResearch.ts`
  - `isMarketResearchRunEnabled()` 추가.
  - `POST /api/market-research/runs` 시작 시 실행 허용 여부를 검사한다.
  - 비활성화 상태면 run 생성, 기존 running 정리, HIRA/네이버/Drive 호출 없이 `403`을 반환한다.
  - 차단 메시지: `배포 서버에서는 시장조사 실행이 비활성화되어 있습니다. 시장조사는 로컬 서버에서 실행해주세요.`

- `server/.env`
  - 로컬 개발 서버용으로 `MARKET_RESEARCH_RUN_ENABLED=true` 추가.

- `.agents/skills/createtree-office-ops/SKILL.md`
  - 배포 서버는 시장조사 실행만 차단하고 결과 조회/수정/엑셀/영업관리 이동은 허용하는 운영 규칙을 추가했다.

## 운영 설정

- 로컬 `server/.env`
  - `MARKET_RESEARCH_RUN_ENABLED=true`

- Railway Variables
  - `MARKET_RESEARCH_RUN_ENABLED=false`
  - 값을 아예 설정하지 않아도 `NODE_ENV=production`이면 기본 차단된다.

## 영향 범위

- 차단되는 기능:
  - `POST /api/market-research/runs`
  - 시장조사 실행 버튼을 통한 신규 수집

- 계속 가능한 기능:
  - 시장조사 결과 목록 조회
  - 필터/검색
  - 항목 수정
  - 엑셀 다운로드
  - 선택업체 저장
  - 영업관리로 이동
  - 모니터링 및 다른 Google/Naver/HIRA 키 사용 기능
