# 시장조사 병원 수집기 구현 인수인계

## 변경 파일

- `server/src/services/sales/marketResearchCollector.ts`
- `client/src/hooks/useMarketResearch.ts`
- `client/src/pages/MarketResearchPage.tsx`

## 핵심 변경 내용

- 산부인과/여성병원 시장조사가 샘플 데이터에 머물던 문제를 수정했다.
- HIRA 병원정보서비스 `getHospBasisList`를 실제 호출하도록 구현했다.
  - 산부인과 진료과목 코드 `dgsbjtCd=10` 사용
  - 대학병원, 상급종합, 종합병원, 병원, 의원을 제외하지 않고 산부인과 진료과목 보유 기관 전체 조회
  - 지역 필터는 HIRA 시도 코드로 변환
  - XML 응답을 파싱해 병원명, 주소, 전화번호, 홈페이지, 좌표, 기관종별, 의료진 수를 저장
- HIRA 기관종별에 따른 초기 분류 기준을 조정했다.
  - 상급종합/종합병원/일반 병원 등 큰 병원은 시장조사 원본 보존을 위해 `obgyn`으로 저장
  - 여성병원 명칭은 `women_hospital`
  - 산부인과병원/분만 명칭은 `delivery_hospital`
  - 의원급은 `general_obgyn`
- Google Places Text Search 보강을 추가했다.
  - HIRA 결과의 상호/주소로 장소 검색
  - 홈페이지, 전화번호, 좌표, Google Maps URL, 폐업 상태를 보강
  - 보강 실패는 전체 실행 실패로 처리하지 않고 run `errorLog`에 기록
- 수집 결과 병합 로직을 추가했다.
  - HIRA 병원/의원 결과와 기존 산후조리원 Drive CSV 결과를 `stableKey` 기준으로 중복 제거 후 병합
  - 실제 원천 결과가 없을 때만 검증용 샘플 데이터로 fallback
- 선택 가능한 런타임 제한값을 추가했다.
  - `MARKET_RESEARCH_HIRA_ROWS_PER_PAGE` 기본 100
  - `MARKET_RESEARCH_HIRA_MAX_ROWS` 기본 10000
  - `MARKET_RESEARCH_GOOGLE_PLACES_LIMIT` 기본 50
- 시장조사 실행 중 UI 상태 유지를 추가했다.
  - `market_research_runs`를 5초마다 재조회
  - 최신 run이 `pending` 또는 `running`이면 페이지 이동/새로고침 후에도 실행 버튼을 `시장조사 진행 중` 로딩 상태로 표시
  - 실행 중에는 결과 목록도 5초마다 자동 갱신
  - 최신 run이 `completed`, `partial_failed`, `failed`로 바뀌면 결과 목록을 한 번 강제 갱신
- 화면 분류 라벨을 보정했다.
  - `obgyn`은 특정 병원 유형이 아니라 HIRA 산부인과 진료과목 보유기관 전체를 뜻하므로 `산부인과 보유기관`으로 표시

## 검증 결과

- ✅ HIRA 서울 산부인과/여성병원 소량 수집 검증
  - `MARKET_RESEARCH_HIRA_MAX_ROWS=5`
  - `MARKET_RESEARCH_GOOGLE_PLACES_LIMIT=2`
  - `고은빛여성병원` 등 실제 HIRA 결과가 반환되고 Google Places 보강이 적용되는 것을 확인
- ✅ 사용자 피드백 반영: 시장조사는 전체 자료 수집이 우선이므로 대학병원/상급종합/종합병원 제외 필터 제거
- ✅ 재검증: `MARKET_RESEARCH_HIRA_MAX_ROWS=3`, `MARKET_RESEARCH_GOOGLE_PLACES_LIMIT=1` 조건에서 서울 `obgyn` 수집 시 `강북삼성병원`, `건국대학교병원`, `경희대학교병원` 같은 상급종합 병원이 `obgyn` 분류로 반환되는 것을 확인
- ✅ `npm run build --prefix server`: 통과
- ✅ `npm run build --prefix client`: 통과
- ⚠️ client Vite chunk size warning은 기존 번들 크기 경고로 이번 변경과 무관
- ✅ 시장조사 진행 상태가 서버 run 상태 기준으로 유지되도록 프론트 로딩 조건 변경

## 다음 작업 참고

- HIRA 병원정보서비스는 산부인과 진료과목 보유 기관 기준이라 분만 건수는 제공하지 않는다. 분만 건수는 별도 공식 통계 원천이 확인되면 추가 연동해야 한다.
- 요양병원도 HIRA에서 산부인과 진료과목을 가진 기관이면 시장조사 원본에 포함된다. 시장조사는 전체 수집이 우선이며, 영업 제외/선별은 사용자가 결과에서 판단한다.
- Google Places 보강은 비용/쿼터 보호를 위해 기본 50건만 수행한다. 필요 시 `MARKET_RESEARCH_GOOGLE_PLACES_LIMIT`로 조정한다.
