# 인수인계: 할인 정책 — 금액 할인 유형 추가

- **작업일**: 2026-03-19
- **순번**: 3
- **작업자**: AI (Antigravity)

---

## 1. 변경 개요

서비스 관리 페이지의 **계약 기간별 할인 정책**에 기존 **% 할인** 외에 **금액 직접 입력 할인(만원 단위)** 유형을 추가했습니다.

### 목적
- 기존: `discountRate`가 항상 백분율(%)로만 동작
- 변경 후: `discountType` 필드를 통해 `percentage`(% 할인)과 `fixed_amount`(만원 할인) 중 선택 가능

## 3. 핵심 변경 내용

### 3-1. DB 스키마 (`schema.ts`)
```diff
 // contractDiscountPolicies 테이블
+  discountType: text("discount_type").default("percentage").notNull(),
   discountRate: integer("discount_rate").notNull(),
```
- `discountType`: `'percentage'` 또는 `'fixed_amount'`
- `discountRate`의 의미: percentage → 백분율(5=5%), fixed_amount → 만원 단위 금액

### 3-2. 견적서 할인 계산 (`QuotationsPage.tsx`)
```typescript
// 변경 전
const discountAmount = subtotal * policy.discountRate / 100;

// 변경 후
const discountAmount = policy.discountType === 'fixed_amount'
  ? policy.discountRate        // 직접 금액 차감
  : subtotal * policy.discountRate / 100;  // % 계산
```

### 3-3. 관리 UI (`ServiceProductsPage.tsx`)
- 기존 `% 할인` 고정 텍스트 → `<select>` 드롭다운으로 교체
- 옵션: `% 할인`, `만원 할인`
- 새 정책 추가 시 기본값: `percentage`
