# 상단 메뉴 위치 조정 인수인계

## 변경 파일

- `client/src/components/NavBar.tsx`

## 핵심 변경 내용

- 좌측 일반 메뉴에서 `시장조사`, `영업관리`를 제거했다.
- 우측 관리 메뉴 배열에 `자료실`, `시장조사`, `영업관리`를 포함해 아래 순서로 표시되도록 정리했다.
  - `거래처 관리`
  - `상품 관리`
  - `자료실`
  - `시장조사`
  - `영업관리`
- 기존 `자료실` 단독 렌더링 블록을 제거하고 우측 관리 메뉴 렌더링 루프에 통합했다.
- `시장조사`, `영업관리` 활성 상태도 우측 관리 메뉴와 동일한 emerald 스타일로 표시되도록 `matchPaths`에 포함했다.

## 검증 결과

- ✅ `npm run build --prefix client`: 통과
- ⚠️ Vite chunk size warning은 출력됐으나 이번 메뉴 변경과 무관한 번들 크기 경고다.

## 다음 작업 참고

- 운영 DB/API 변경 없음.
- 스킬 문서 업데이트 필요 없음: 새 운영 규칙이나 반복 개발 절차가 생기지 않은 단순 메뉴 배치 변경이다.
