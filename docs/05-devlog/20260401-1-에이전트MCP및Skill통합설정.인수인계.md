## 1. 개요 및 작업 목적
현재 사용 중인 AI 에이전트 개발 환경(Antigravity)의 능력을 `createtree-office` 시스템 아키텍처(React + Express + PostgreSQL 기반)에 최적화되도록 고도화하였습니다.
본 문서는 로컬 PC에서 진행된 **외부 도구(MCP 서버)**와 **프로젝트 맞춤형 제어 규칙(Skill)** 설정 내역을 기록하며, **다른 개발 환경(사무실/노트북)에서 동일한 에이전트 환경을 구축(복제)하기 위한 매뉴얼**로 활용됩니다.

---

## 2. 💻 다른 PC(사무실/노트북)에 동일 환경 구축 매뉴얼 (필독)

이 설정들은 프로젝트 루트 폴더가 아닌, 각 PC의 `~/.gemini/antigravity` 로컬 폴더에 저장됩니다. 따라서 기기를 변경했을 때는 다음 **두 가지 절차 중 하나**를 따라 환경을 동기화해야 합니다.

### 방법 A. 초간단 자동 동기화 (AI에게 위임하기)
가장 쉽고 빠른 방법입니다. 다른 PC에서 프로젝트를 열고 이 문서를 띄운 뒤, 에이전트(AI)에게 다음 문장을 복사해서 전송하세요.

> **"이 인수인계 문서(20260401-1-에이전트MCP및Skill통합설정.인수인계.md)를 읽고, 현재 내 환경에도 똑같이 MCP와 Skill 3종을 설치 및 설정해 줘. (단, GitHub 토큰은 기존에 발급받은 `[토큰값]`을 사용할 것)"**

위 한 문장이면 AI가 알아서 폴더를 만들고 JSON을 세팅하여 10초 만에 환경 구축을 완료합니다.

### 방법 B. 수동으로 직접 복사/붙여넣기 
AI에 의존하지 않고 직접 세팅하고 싶다면 다음 절차를 따릅니다.

#### 1단계: MCP 설정 파일 세팅
1. 새 PC에서 `C:\Users\[사용자명]\.gemini\antigravity\mcp_config.json` 파일을 엽니다. (없으면 새로 만듭니다.)
2. 아래 코드를 복사해서 파일 전체에 덮어씌웁니다.
3. `GITHUB_PERSONAL_ACCESS_TOKEN` 부분에는 본인의 토큰(ghp_xxxx...)을 넣습니다.

```json
{
  "mcpServers": {
    "postgres": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-postgres",
        "postgresql://neondb_owner:npg_ipIEzLgjb79Y@ep-icy-resonance-a1sco794-pooler.ap-southeast-1.aws.neon.tech/neondb?sslmode=require&channel_binding=require"
      ]
    },
    "github": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-github"
      ],
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "여기에_발급받은_GitHub_토큰(PAT_Classic)_입력"
      }
    },
    "puppeteer": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-puppeteer"
      ]
    }
  }
}
```

> **🔥 GitHub 토큰 발급법 (기억 안 날 때 참고)**
> 1. GitHub -> Settings -> Developer settings -> Personal access tokens -> Tokens (classic)
> 2. Generate new token (classic) 클릭
> 3. Note에 이름 작성, 권한에서 `repo`, `read:org`, `user` 체크 후 생성
> 4. 생성된 `ghp_...` 키 복사

#### 2단계: Skill 내용 복구
에이전트가 코딩할 때 절대 잊으면 안 되는 핵심 가이드라인입니다. 안티그래비티 설정 창에서 오류가 나지 않도록 `~/.gemini/antigravity/skills/` 폴더 아래에 다음 3개의 폴더와 `SKILL.md`를 만들어야 합니다. (이 부분은 '방법 A'의 AI 위임 방식을 강력히 추천합니다.)

1. `drizzle-guru/SKILL.md`: `server/src/db/schema.ts` 수정 시 `db:push` 강제 규칙
2. `tiptap-master/SKILL.md`: 리치 텍스트 Tiptap JSON 파싱 데이터 오염 방지 규칙
3. `pdca-workflow/SKILL.md`: GEMINI.md의 Plan-Design-Devlog 작성 자동화 정책
