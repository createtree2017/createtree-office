# 20260323-3 거래처관리UI단순화 + 견적서/계약서 연결 시스템

## 작업 일시
- 2026-03-23 (오후, 2차 업데이트)

## 작업 요약
거래처 관리 시스템을 전면 단순화. 이후 추가로:
1. 견적서 상태를 5단계 → 3단계(초안/제안중/승인)로 변경
2. 거래처 카드에서 견적서/계약서 수동 연결 시스템 구현
3. 연결된 문서 바로가기 기능 구현

| 파일 | 변경 내용 |

| `client/src/pages/AdminPage.tsx` | 전면 재작성. 수동 연결 모달, 연결됨/연결안됨 버튼, ⚙ 아이콘 추가 |
| `client/src/components/SubNav.tsx` | '계약 종료' 탭 제거 |

## 핵심 변경 내용

### 1. 견적서 상태 3단계 변경
- **DB enum**: `quotation_status`: `draft/sent/accepted/rejected/expired` → `draft/proposed/approved`
- **마이그레이션**: 기존 `sent` → `proposed`, `accepted` → `approved`, 나머지 → `draft`
- **프론트**: 상태 라벨(초안/제안중/승인) + 색상 + 버튼 변경
- **상태 전환 흐름**: 초안 → 제안중 → 승인, 각 단계에서 이전/다음 전환 가능

### 2. 거래처-견적서/계약서 수동 연결
- **DB**: `clients` 테이블에 `linked_quotation_id`, `linked_contract_id` 컬럼 추가
- **백엔드**: `PATCH /api/clients/:id/link` API (연결/해제)
- **프론트**:
  - 버튼에 `연결됨`/`연결안됨` 표시
  - hover 시 ⚙ 아이콘 노출 → 클릭 시 연결 모달 오픈
  - 모달: 해당 거래처의 승인된 견적서 / 서명·활성 계약서 목록만 표시
  - 연결/해제 한 번 클릭으로 즉시 반영

### 3. 연결된 문서 바로가기
- 연결됨 버튼 클릭 → `/quotations?viewId=ID` 또는 `/contracts?viewId=ID`
- QuotationsPage/ContractsPage에서 `viewId` 파라미터 감지 → 자동 상세 보기 오픈
- 연결 안 됨 버튼 클릭 → `/quotations?clientId=ID` (해당 거래처 필터)

### 4. 실행 서비스 카드 표시
- 기존 계약서 API → 승인 견적서 API로 변경
- `GET /api/quotations/client/:clientId/approved-services` 엔드포인트 추가
- 승인된 견적서의 서비스 설정을 거래처 카드에 배지로 표시
