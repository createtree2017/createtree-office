## 핵심 변경 내용

- `develop` 브랜치로 전환 후 작업했다.
- 시장조사 원본과 영업선택업체를 분리하는 DB 구조를 추가했다.
  - 시장조사 실행, 조사 항목, 변경 로그
  - 영업선택업체, 영업활동, 영업자료, 발송이력
- 시장조사 API를 추가했다.
  - 조사 실행, 결과 목록/수정, 영업선택 저장/해제, 변경이력, 엑셀 다운로드
  - 외부 API 키가 없는 개발 환경에서도 샘플 조사 구조로 화면/API 검증 가능
- 영업관리 API를 추가했다.
  - 영업선택업체 목록/상세/수정/보관 제외
  - 전화, 메일, SNS, 방문, 미팅, 피드백 활동 기록
- 영업자료/메일 API를 추가했다.
  - 영업자료 등록/수정/비활성화
  - 다건 발송 처리
  - Resend 설정이 없거나 이메일 없음/폐업/수신거부 업체는 실제 발송하지 않고 초안 또는 차단 로그 저장
- 프론트엔드에 `시장조사`, `영업관리` 메뉴와 페이지를 추가했다.
  - 시장조사: 지역/업체/운영상태/표시상태 필터, 상태 아이콘, 일괄 영업선택, 조사 실행, 엑셀 다운로드, 상세 편집
  - 영업관리: 선택 업체 목록, 영업상태 변경, 활동 기록, 영업자료 등록, 자료 발송 처리
- Skill Impact Check에 따라 시장조사/영업관리/메일 발송 흐름을 스킬 문서에 반영했다.

## DB 적용 주의사항

- 운영 DB에는 아직 적용하지 않았다.
- 적용 전 `server/drizzle/0004_careless_roulette.sql`을 검토한 뒤 `npm run db:push --prefix server` 또는 운영 기준에 맞는 migration 적용을 별도 승인 후 진행해야 한다.
- 신규 API는 DB 테이블이 생성되기 전까지 실제 런타임 호출 시 500이 발생할 수 있다.
