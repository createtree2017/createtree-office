## 2. 작업 1: 메뉴 구조 재편

### 변경 내용

**Before**: 거래처 관리 / 상품 관리가 드롭다운 메뉴 (클릭 시 하위 항목 펼쳐짐)
```
[거래처 관리 ▼]  →  펼침: 회원관리, 병원관리, 견적관리, 계약관리, 계약종료
[상품 관리 ▼]    →  펼침: 템플릿관리, 서비스관리
```

**After**: 원버튼 직행 + 각 페이지에 공통 SubNav 탭 바
```
[거래처 관리]  →  /admin?tab=users 직행, SubNav에서 탭 전환
[상품 관리]    →  /templates 직행, SubNav에서 탭 전환
```

### 신규 파일
| 파일 | 설명 |
|------|------|
| `client/src/components/SubNav.tsx` (~120줄) | 거래처/상품 그룹 공통 헤더+탭 바 컴포넌트 |

### 수정 파일
| 파일 | 변경 내용 |
|------|----------|
| `client/src/components/NavBar.tsx` | 전면 재작성 — `NavDropdown` 컴포넌트 제거, 원버튼 직행 |
| `client/src/pages/AdminPage.tsx` | 기존 헤더+탭바 → `<SubNav group="client" />` |
| `client/src/pages/QuotationsPage.tsx` | 기존 헤더 → `<SubNav group="client" rightSlot={...} />` |
| `client/src/pages/ContractsPage.tsx` | 기존 헤더 → `<SubNav group="client" />` |
| `client/src/pages/TemplatesPage.tsx` | 기존 헤더 → `<SubNav group="product" rightSlot={...} />` |
| `client/src/pages/ServiceProductsPage.tsx` | 기존 헤더 → `<SubNav group="product" rightSlot={...} />` |

### SubNav 라우팅 구조

```
거래처 관리 그룹:
[회원관리] /admin?tab=users
[병원관리] /admin?tab=clients
[견적관리] /quotations         ← 별도 페이지 (라우트 분리)
[계약관리] /contracts          ← 별도 페이지 (라우트 분리)
[계약종료] /admin?tab=terminated

상품 관리 그룹:
[템플릿관리] /templates        ← 별도 페이지 (라우트 분리)
[서비스관리] /services         ← 별도 페이지 (라우트 분리)
```

> **핵심**: 사용자에게는 "같은 페이지 내 탭 전환"처럼 보이되, 내부적으로는 라우트 분리 유지

### 라우트 변경: **없음** (기존 구조 그대로)

## 3. 작업 2: GEMINI.md 지침 정비

### §4.5 아키텍처 규칙 — 탭/하위메뉴 라우팅 분리 원칙 추가

기존 `라우터 분리` 규칙 하위에 3개 항목 추가:
- 독립 도메인(자체 API·상태·비즈니스 로직)이면 탭이라도 별도 페이지 컴포넌트로 분리
- 공통 탭 바를 재사용 컴포넌트로 만들어 import
- UX는 같은 페이지처럼, 내부는 라우트 분리 유지

### §5 문서 규칙 — 일일 개발 인수인계 지침 추가

- `docs/05-devlog/` 폴더 및 파일명 규칙 추가
- 작성 시점, 포함 내용 명시

### §6 응답 규칙 — `!!인수인계!!` 키워드 추가

기존 `!!질문!!` / `!!승인!!`과 동일 패턴으로 추가:
- 범위 판단: devlog 최신 파일 → git log/diff → 대화 내역 참조
- 순번 자동 결정, 작업 단위별 분리
- 코드 수정 없이 문서 작성만 수행

## 5. 작업 4: NavBar 관리 메뉴 우측 이동 + 활성 색상 변경

### 변경 내용

**Before**: 거래처관리/상품관리가 왼쪽 사용자 메뉴 옆에 파란 활성색
```
좌측: [홈] [매뉴얼] [업무] [자료실] [모니터링] | [거래처관리] [상품관리]
우측: [🟢드라이브] [🌙] [프로필]
```

**After**: 관리 메뉴를 우측으로 분리, 초록색 활성
```
좌측: [홈] [매뉴얼] [업무] [모니터링]        (파란 활성)
우측: [거래처관리] [상품관리] [자료실] [🌙] [프로필]  (초록 활성)
```

### 세부 변경
| 항목 | Before | After |
|------|--------|-------|
| 거래처관리/상품관리 위치 | 좌측 | 우측 |
| 활성 색상 | 파란색 (`bg-blue-600`) | 초록색 (`bg-emerald-600`) |
| 드라이브 버튼 | 항상 초록 배경 외부 링크 | **삭제** |
| 자료실 메뉴 | 좌측 사용자 메뉴 | 우측 관리 메뉴 영역 (초록 활성) |
