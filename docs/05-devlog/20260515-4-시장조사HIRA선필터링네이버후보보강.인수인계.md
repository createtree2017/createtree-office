# 시장조사 HIRA 선필터링 네이버 후보 보강 인수인계

## 작업 배경

- 기존 전체 실행은 HIRA 기본목록 이후 네이버 지역검색을 5천 건 이상에 순차 호출해 실행 시간이 과도하게 길었다.
- 네이버 공식 지역검색 API는 카테고리 전체 목록 조회가 아니라 검색어 기반 API라 산부인과 전체 플레이스 목록을 직접 가져올 수 없다.
- 따라서 HIRA로 분만 가능성이 높은 후보를 먼저 줄이고, 네이버는 카테고리/플레이스 URL 보강용으로만 호출하도록 변경했다.
- 전체 시장조사는 실행하지 않았다.

## 변경 내용

- `server/src/services/sales/marketResearchCollector.ts`
  - 수집 순서를 변경했다.
    - HIRA 산부인과 진료과목 보유기관 기본목록 수집
    - HIRA 진료과/전문의 상세 조회
    - 산부인과 전문의 3명 이상, 소아청소년과 여부로 1차 점수 계산
    - 1차 점수가 1점 이상인 기관만 HIRA 의료장비 상세 조회
    - 인큐베이터, 분만감시기 여부를 반영해 4개 조건 중 3개 이상이면 분만산부인과 후보
    - 분만산부인과 후보만 네이버 지역검색 보강
    - Google Drive 산후조리원 CSV 병합
  - 네이버 지역검색은 전체 원본이 아니라 `deliveryCandidate.score >= 3` 또는 `isDeliveryHospital=true` 후보만 호출한다.
  - 네이버 실패/미확인은 후보 제외 사유가 아니며 HIRA 후보를 유지한다.
  - 네이버 보강값은 `rawData.naverLocal`, `rawData.naverPlaceUrl`, `rawData.naverCategoryMatched`에 저장한다.
  - `onProgress` 콜백과 `MarketResearchProgressStats`를 추가해 수집 단계별 진행 상태를 보고한다.

- `server/src/routes/marketResearch.ts`
  - `market_research_runs.stats`에 단계별 진행 상태를 저장한다.
  - 기록 필드:
    - `stage`
    - `processed`
    - `total`
    - `hiraBaseCount`
    - `hiraDetailProcessed`
    - `equipmentProcessed`
    - `deliveryCandidateCount`
    - `naverProcessed`
    - `inserted`
    - `updated`
    - `changed`
    - `errors`
  - 새 시장조사 실행 시 이전 `running` run은 `failed/interrupted`로 안전 중단 처리한다.
  - 예외 발생 시 생성된 run을 `failed`로 종료하고 `errorLog`를 남긴다.
  - DB 저장 단계에서도 진행률을 갱신한다.

- `client/src/pages/MarketResearchPage.tsx`
  - 진행 중 배너에 현재 단계, 처리량, 진행률 bar를 표시한다.
  - HIRA 기본 수집 수, 진료과 처리 수, 장비 처리 수, 분만후보 수, 네이버 처리 수, 오류 수를 표시한다.
  - 새로고침 후에도 `useMarketResearchRuns` polling으로 최신 `stats`를 확인할 수 있다.

- `.agents/skills/createtree-office-ops/SKILL.md`
  - 시장조사 기준을 HIRA 선필터링 후 네이버 후보 보강 방식으로 업데이트했다.

- `.agents/skills/SKILLS_INDEX.md`
  - 스킬 변경 후 `npm run skills:sync`로 동기화했다.

## 실행/정리 결과

- 기존 실행 중이던 `run id=5`는 서버 수집 로직 수정으로 중단될 수 있어 `failed/interrupted`로 안전 정리했다.
- 정리 사유는 `errorLog`에 `수집 로직 개선 작업으로 기존 running 실행을 안전 중단 처리했습니다.`로 남겼다.

## 운영 참고

- `MARKET_RESEARCH_NAVER_LOCAL_LIMIT=300`은 이제 전체 원본 제한이 아니라 분만산부인과 후보 중 네이버 보강 상한이다.
- HIRA 상세 조회는 여전히 외부 API 호출이 많으므로 `MARKET_RESEARCH_HIRA_DETAIL_LIMIT=3000` 기준으로 운영한다.
- HIRA 1차 점수가 0점인 기관은 장비 2개 조건만으로 총 3점에 도달할 수 없어 장비 상세 조회 대상에서 제외한다.
- 네이버 카테고리가 미확인이어도 HIRA 3점 이상 후보는 유지된다.
