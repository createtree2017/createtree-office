# 20260331-4 업무 칸반 수동 정렬(Drag & Drop) 및 모달 UI 개편

## 작업 요약
- 업무 칸반 리스트의 드래그 앤 드롭 기능을 통해 **순번대로 자유 정렬**이 가능하도록 프론트/백엔드 수정.
- 칸반의 특정 위치에 떨군 카드가 **새로고침 시에도 그 위치를 기억**하도록 로직 구현 (`sortOrder` 도입).
- 업무 상세 페이지(모달창 `TaskDetailModal`)에서 템플릿(거래처) 정보 뱃지가 누락되었던 문제를 보완, 제목 하단에 거래처 표시 추가 완.
- 데이터베이스 Push 작업 시 기존 서버에서 구동 중이던 테이블(`supporter_applicants`)의 유실 위험을 발견하여, Drizzle-kit push 를 취소하고 **스크립트 명령어(`ALTER TABLE`) 기반의 안전한 컬럼 추가 작업** 수행.

## 변경 파일 목록
- `client/src/pages/TasksPage.tsx`: `Task` 인터페이스에 `sortOrder` 속성 추가, API 구조 및 상태/필터에 따른 드래그 방어 로직(`selectedClientId !== 'ALL'` 일시 잠금) 고도화, onDragEnd 배열 계산 로직 추가. 카드 내 템플릿 명칭 표시 추가(`거래처 | [템플릿]`). 상단 거래처 필터 정렬 기준을 개수순에서 '내부업무 최우선 및 가나다순'으로 개편. 거래처 필터 개수 산정 시 완료(COMPLETED) 상태 제외 및 안내 문구 추가.
- `client/src/components/TaskDetailModal.tsx`: 업무 제목 하단에 `{task.clientName} | [{task.templateTitle}]` 정보 복합 렌더링 뱃지 추가
- `server/src/db/schema.ts`: `tasks` 테이블 정의에 `sortOrder: integer("sort_order").default(0).notNull()` 구문 추가.
- `server/src/routes/tasks.ts`:
  - `GET /api/tasks` 조회 시 `desc(tasks.updatedAt)`를 `asc(tasks.sortOrder), desc(tasks.updatedAt)`로 정렬 로직 보완.
  - 드래그 뚝 떨어졌을 때 다중 요소들을 한 번에 저장하는 `PUT /api/tasks/reorder` 신규 라우터 신설.
  - **[Bugfix]** 업무 수정(`PATCH /api/tasks/:id`) 엔드포인트에서 `clientId`와 `templateId`가 `req.body`에서 누락되어 DB에 업데이트되지 않던 버그 수정.
- `server/scripts/add-sortorder-col.ts` (신규): 안전한 DB 마이그레이션을 위한 `tasks` 테이블 컬럼 수동 추가 스크립트 작성 (실행 완료 후 유지 필요 없음).

## 동작 확인 상태
- ✅ 업무 수정 모달에서 거래처(Client) 및 적용 템플릿(Template) 변경 후 저장 시 정상적으로 DB 및 뷰에 반영 완료
- ✅ 칸반 보드 카드 드래그 시 해당 위치로 삽입 및 API 통신 성공 / 새로고침 시 위치 복원 확인 완료
- ✅ 거래처 필터 선택 시 "필터 중에는 순서를 바꿀 수 없다"는 Toast 에러 방지턱 작동 확인 완료
- ✅ 업무 클릭 시 모달창에서 '🏢 포유문산부인과' 등 정상적인 뱃지 형태 렌더링 확인 완료

## 다음 작업 참고사항
- Drizzle ORM 의 스키마 파일(`schema.ts`) 내에, 이전에 사용하던 `supporter_applicants` 등의 구인구직 테이블 형식이 빠져 있어 전체 Push 진행 시 삭제(Data-loss) 경고가 발생했음을 인지. 만일 추후 해당 테이블을 삭제하는게 맞았다면 정리 후 Push 필요. 당분간 단일 컬럼 추가 등은 안전하게 `ALTER TABLE` 스크립트 사용을 권장.
- 프론트/백엔드 안정성이 확보되었으므로, 다음 세션에서 Git Push 를 진행하여 운영서버 배포 가능.
