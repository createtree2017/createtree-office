# 분만병원 후보 선별 로직 구현 인수인계

## 작업 배경

- 시장조사 원본에는 HIRA 산부인과 진료과목 보유기관 전체를 보존해야 한다.
- 영업 우선순위는 별도로 분만 가능성이 높은 병원/의원을 선별해야 한다.
- 구글은 국내 산부인과 영업 기준에서 핵심 신뢰 정보가 적고 비용 가능성이 있어 기본 흐름에서 제외한다.

## 변경 내용

- `server/src/services/sales/marketResearchCollector.ts`
  - Google Places 기본 보강 흐름을 제거했다.
  - 네이버 지역검색 API를 추가했다.
    - HIRA 병원명 + 주소로 검색한다.
    - 네이버 카테고리가 `병원,의원>산부인과`이면 상세조사 후보로 표시한다.
    - 카테고리가 맞지 않아도 기관명에 `여성병원`, `산부인과병원`, `산부인과`, `미즈`, `우먼`, `모아`, `맘`, `아이`가 있으면 상세조사 후보로 표시한다.
    - HIRA 기관종별이 병원/종합병원/상급종합이라는 이유만으로 상세조사 후보에 넣는 예외는 적용하지 않는다.
    - 429 속도제한 완화를 위해 호출 간격, 재시도, exponential backoff, jitter를 적용했다.
    - 긴 HIRA 주소로 네이버 검색이 실패하는 경우를 줄이기 위해 `지역+상호`, `상호+짧은주소`, `상호` 순서로 fallback 검색한다.
  - HIRA 의료기관별상세정보서비스 호출 로직을 추가했다.
    - `MadmDtlInfoService2.7/getSpcSbjtSdrInfo2.7`: 전문과목별 전문의 수
    - `MadmDtlInfoService2.7/getMedOftInfo2.7`: 의료장비/보유대수
  - 상세조사 후보만 HIRA 상세 API를 호출한다.
  - 분만 후보 4개 조건을 점수화한다.
    - 산부인과 의사 3명 이상
    - 소아청소년과 의사 있음
    - 인큐베이터 있음
    - 분만감시기 있음
  - 3점 이상이면 `isDeliveryHospital=true`, `businessType=delivery_hospital`로 저장한다.
  - 상세 근거는 기존 DB 컬럼 추가 없이 `rawData.deliveryCandidate`에 보존한다.

- `server/src/routes/marketResearch.ts`
  - 변경 추적 필드에 분만 후보 관련 필드를 추가했다.
  - 시장조사 실행 통계에 상세조사 후보 수와 분만 후보 수를 추가했다.
  - `delivery_hospital` 필터가 `businessType` 문자열만 보지 않고 `isDeliveryHospital`/후보 점수 기준으로 동작하도록 수정했다.
  - 엑셀 다운로드에 분만 후보 점수, 산부인과/소아청소년과 의사 수, 인큐베이터, 분만감시기, 네이버 카테고리, 상세조사 후보 여부를 추가했다.

- `client/src/pages/MarketResearchPage.tsx`
  - 요약 카드에 분만후보 수를 추가했다.
  - 표의 진료/의료진 칸에 산부인과 의사 수와 소아청소년과 의사 수를 표시한다.
  - 표의 분만후보 칸에 후보 등급, 4점 기준 점수, 인큐베이터/분만감시기 수, 네이버 카테고리 또는 기관명 예외 근거를 표시한다.

- `client/src/hooks/useMarketResearch.ts`, `shared/types.ts`
  - `rawData`, `hasDeliveryCenter`, `hasFertilityCenter`, `hasPediatricLink` 타입을 보강했다.

- `server/scripts/test-market-research-production-sample.ts`
  - 전체 시장조사 없이 고은빛 샘플만 수집해 프로덕션 핵심 흐름을 검증한다.
  - HIRA 기본목록, 네이버 카테고리, HIRA 전문의 수, HIRA 의료장비, 분만 후보 점수를 확인한다.

- `client/package.json`, `client/.eslintrc.cjs`
  - 시장조사 관련 파일 전용 lint 스크립트를 추가했다.
  - `npm run lint:market-research --prefix client`

- `.agents/skills/createtree-office-ops/SKILL.md`
  - 시장조사 HIRA+네이버 기준과 Google Places 기본 제외 규칙을 반영했다.

## 신규/변경 환경변수

- 기존 사용
  - `PUBLIC_DATA_SERVICE_KEY` 또는 `HIRA_SERVICE_KEY`
  - `NAVER_CLIENT_ID`
  - `NAVER_CLIENT_SECRET`

- 신규 조절값
  - `MARKET_RESEARCH_NAVER_LOCAL_LIMIT`
    - 기본값: `10000`
    - 네이버 지역검색 최대 호출 수
  - `MARKET_RESEARCH_NAVER_DELAY_MS`
    - 기본값: `350`
    - 네이버 지역검색 호출 간격
  - `MARKET_RESEARCH_NAVER_RETRY_DELAY_MS`
    - 기본값: `2000`
    - 네이버 429/5xx 재시도 기본 대기 시간
  - `MARKET_RESEARCH_NAVER_MAX_RETRIES`
    - 기본값: `3`
    - 네이버 429/5xx 최대 재시도 횟수
  - `MARKET_RESEARCH_HIRA_DETAIL_LIMIT`
    - 기본값: `3000`
    - HIRA 상세조사 후보 최대 처리 수

## 운영 참고

- HIRA 기본목록은 산부인과 진료과목 보유기관 전체를 저장한다.
- 네이버 카테고리와 기관명 예외는 상세조사 대상을 줄이기 위한 필터다.
- 분만병원 후보 판정은 HIRA 상세정보 기반 4개 조건 중 3개 이상 충족 기준이다.
- HIRA 의료기관별상세정보서비스는 병원정보서비스와 별도 Open API다.
- 2026-05-15 확인 결과 승인된 실제 endpoint는 구형 `medicInsttDetailInfoService`가 아니라 `MadmDtlInfoService2.7`이다.
- `getSpcSbjtSdrInfo2.7`, `getMedOftInfo2.7` 직접 호출이 200으로 정상 응답함을 확인했다.
