# 스킬 설치 및 운영 자동화 인수인계

## 변경 파일

- `.agents/skills/`
- `.agents/scripts/generate_skills_index.py`
- `.agents/scripts/validate_skills.py`
- `.agents/skills/SKILLS_INDEX.md`
- `GEMINI.md`
- `package.json`

## 핵심 변경 내용

- Codex repo-local 스킬 위치를 `.agents/skills/`로 구성했다.
- CT_office 전용 스킬 6개를 추가했다.
  - `createtree-office-ops`
  - `office-drizzle-guardian`
  - `office-tiptap-richtext`
  - `office-pdca-workflow`
  - `office-google-workspace`
  - `office-pdf-contracts`
- 공통 품질 스킬 7개를 설치했다.
  - `security-best-practices`
  - `react-best-practices`
  - `web-design-guidelines`
  - `web-quality-audit`
  - `performance`
  - `accessibility`
  - `use-railway`
- `.agents/skills/SKILLS_INDEX.md`를 자동 생성 목록 문서로 추가했다.
- `npm run skills:sync`, `npm run skills:check`, `npm run verify` 명령을 추가했다.
- `GEMINI.md`에 Skill Impact Check와 운영 정책 변경 기준을 추가했다.

## 왜 변경했는지

CT_office는 사내 업무, 거래처, Drive 자료실, 견적/계약, PDF, Tiptap 매뉴얼, Railway DB가 연결된 운영 포털이다. 반복 작업 기준을 스킬로 분리하고 스킬 목록 최신성 검증을 자동화해, 기능 변경 후 AI가 오래된 규칙으로 작업하지 않게 만들기 위해 변경했다.

## 검증 결과

- `npm run skills:sync`: 통과
- `npm run skills:check`: 통과
- `npm run build`: 통과
  - Vite chunk size warning은 기존 프론트 번들 크기 경고이며 빌드는 성공했다.

## 주의사항

- `SKILLS_INDEX.md`는 직접 수정하지 말고 `npm run skills:sync`로 재생성한다.
- 기능 개발, 기존 기능 변경, 업데이트 완료 시 Skill Impact Check를 수행한다.
- DB/보안/개인정보/계약·금전/배포/자동화 권한 정책 변경은 사용자 확인 후 스킬에 반영한다.
- git add, commit, push는 수행하지 않았다.

## 추가 보강

- 컨텍스트와 개발 속도 보호를 위해 자동 호출 범위를 프로젝트 전용 핵심 스킬 6개로 제한했다.
- 공통 품질 스킬 7개는 설치 상태를 유지하되 `$스킬명`으로 명시 호출할 때만 사용하도록 `allow_implicit_invocation: false`로 변경했다.
- `npm run skills:sync`와 `npm run skills:check` 재검증을 통과했다.
