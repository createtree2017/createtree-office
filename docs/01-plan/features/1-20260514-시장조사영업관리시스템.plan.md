# 시장조사 영업관리 시스템 Plan

## 목적

창조트리 산부인과/여성병원/산후조리원 영업을 위해 시장조사, 영업대상 선별, 접촉 이력, 자료 발송, 재조사 변경감지를 하나의 업무 흐름으로 관리한다.

## 범위

- 전국/지역별 시장조사 실행 및 결과 누적 보존
- 산부인과+여성병원, 분만병원, 일반 산부인과, 산후조리원 분류 조사
- 폐업, 신규개업, 운영중 상태 확인
- 출생/출산율 등 지역 시장성 지표 저장 구조
- 분만수, 진료과, 의료진 수, 객실/서비스/규모 등 정밀 조사 항목 저장
- 관리자가 조사 결과에서 영업할 업체를 체크해 영업선택업체로 분리 관리
- 영업상태, 활동 타임라인, 자료 발송 이력 관리
- 메일 발송은 Resend 설정이 없으면 초안/차단 로그만 저장
- 전체/필터/영업선택/병원별 엑셀 다운로드
- Google Drive 시장조사 폴더에 올린 산후조리원 CSV를 월별 원본으로 가져와 DB에 누적 저장

## 원칙

- 시장조사 원본은 삭제하지 않고 누적 보존한다.
- 영업선택업체는 조사 원본과 분리된 영업관리 레코드로 둔다.
- 공개 원천으로 확정하기 어려운 항목은 `검증필요`로 저장한다.
- 개인 휴대폰, 비공개 개인 이메일, 무단 추정 이메일은 수집하지 않는다.
- 운영 DB 반영은 별도 승인 전 `drizzle-kit push`를 실행하지 않는다.

## 성공 기준

- 관리자가 시장조사 조건을 만들고 조사 결과를 확인할 수 있다.
- 조사 결과에서 선택한 업체만 영업선택업체 목록으로 모아 볼 수 있다.
- 재조사 시 신규/업데이트/영업선택/폐업 표시가 가능하다.
- 병원/조리원 상세 정보와 영업활동, 자료 발송 이력이 저장된다.
- 메일 설정 부재, 수신거부, 이메일 없음, 폐업 업체는 발송이 차단된다.
- `npm run build`가 통과한다.
