# 견적서 시스템 — Plan

## 목적
거래처(병원)에 서비스를 제안할 때 **디지털 견적서**를 생성하는 시스템.  
Phase 1에서 만든 서비스 상품 마스터의 데이터를 기반으로 서비스를 선택하고, 세부 옵션을 설정하여 견적서를 만든다.

## 비즈니스 플로우
```
거래처 선택 → 서비스 선택 → 등급/옵션 선정 → 가격 확인/조정 → 계약기간 설정
→ 할인 적용(선택) → 결제방식 선택(선택) → 견적서 생성 → (추후) 계약서 변환
```

## 핵심 설계 원칙 (이전 논의 반영)
1. **선택형 자동화** — 할인/분할결제 등 모두 관리자가 선택하면 자동 계산
2. **행사 결제 방식** — 일괄결제 / 계약기간 분할 중 선택
3. **서포터즈 2트랙** — 필수비용(월초) + 변동비용(월말 정산) 분리
4. **계약 할인** — 6개월/12개월 할인 적용 여부 관리자 선택

## 범위

### DB 스키마 (3개 테이블 추가)

**quotations** (견적서)
- id, quotationNumber (자동 채번), clientId (→ clients FK)
- title, contractMonths (계약기간 개월수)
- discountPolicyId (→ contract_discount_policies FK, nullable), discountApplied (boolean)
- subtotal, discountAmount, totalAmount (만원 단위)
- notes (메모), status (draft/sent/accepted/rejected/expired)
- validUntil (견적 유효기간), createdBy (→ users FK)
- timestamps

**quotation_items** (견적 항목)
- id, quotationId (→ quotations FK cascade)
- serviceId, serviceName (시점 보존), tierId, tierName (시점 보존)
- itemId, itemName, itemCategory, itemPriceUnit
- quantity (수량), unitPrice (단가, 시점 고정), amount (소계)
- isRequired, paymentMethod (lump_sum/installment/monthly_settle, nullable)
- sortOrder, timestamps

**quotation_service_configs** (견적 내 서비스별 설정)
- id, quotationId (→ quotations FK cascade)
- serviceId, serviceName, billingType
- selectedTierId, selectedTierName
- eventFrequency (행사 주기, nullable), eventPaymentMethod (lump_sum/installment, nullable)
- notes (서비스별 메모)

### 백엔드 API (server/src/routes/quotations.ts)
| Method | Endpoint | 설명 |
|--------|----------|------|
| GET | /api/quotations | 견적서 목록 |
| GET | /api/quotations/:id | 견적서 상세 |
| POST | /api/quotations | 견적서 생성 |
| PUT | /api/quotations/:id | 견적서 수정 |
| DELETE | /api/quotations/:id | 견적서 삭제 |
| PUT | /api/quotations/:id/status | 상태 변경 |

### 프론트엔드 UI (client/src/pages/QuotationsPage.tsx)
1. **목록 모드** — 견적서 테이블 (번호, 거래처, 금액, 상태, 날짜)
2. **생성/편집 모드** — 단계별 견적서 에디터:
   - Step 1: 거래처 선택 + 계약기간 설정
   - Step 2: 서비스 선택 (상품 마스터에서 로드) + 등급/옵션 선정
   - Step 3: 가격 확인 + 할인/분할결제 옵션 선택
   - Step 4: 최종 견적 요약 + 메모
3. **견적서 상세 뷰** — 인쇄/PDF 형태의 공식 견적서 포맷
