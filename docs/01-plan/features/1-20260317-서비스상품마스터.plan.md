# 서비스 상품 마스터 시스템 — Plan

## 목적
사업운영관리 시스템의 핵심 기반인 서비스 상품 마스터 개발.
창조트리기획의 7가지 서비스(행사, 서포터즈, AI문화센터, AI오피스, 홈페이지, AI자동화, 인테리어)를
동적 데이터 구조로 정확히 표현하는 DB + API + UI 구현.

## 핵심 원칙
1. **선택형 자동화** — 관리자가 선택하면 자동 계산, 강제 자동화 없음
2. **과금 유형 다양성** — 월정액/건당/일회성/견적기반 모두 지원
3. **동적 구조** — 하드코딩 없이 DB 기반 유연한 관리
4. **가격 이력 보존** — 견적 시점 가격 보존 설계

## 범위
- DB 스키마 5개 테이블 + 3개 enum
- 백엔드 REST API 7개 엔드포인트
- 프론트엔드 관리 UI (목록+편집+할인정책)
- 시드 데이터 (CSV 기반 7개 서비스)
