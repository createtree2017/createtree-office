## 1. 프로젝트 개요

### 1.1 목적
- **사내 인수인계 매뉴얼** 관리 (리치 텍스트 에디터 기반)
- **업무(Task) 할당 및 추적** 시스템 (템플릿 기반 양식 응답)
- **거래처(병원) 관리** — 구글 드라이브 자료실 연동/계약 관리/서비스 계약
- **서비스 상품 마스터** — 서비스별 등급/항목/가격 관리
- **견적서 시스템** — 서비스 기반 자동 견적 생성/관리
- **계약서 시스템** — 견적서 기반 계약 전환
- **온라인 평판 모니터링** — 네이버/카카오/구글 리뷰 수집·AI 분석·자동 보고서
- **텔레그램 알림** — 모니터링 결과 자동 발송
- **직원 전용 포털** (RBAC 기반 접근 제어)

## 5. 개발 실행 방법

### 5.1 환경 준비
```bash
npm install                    # 루트에서 실행 → client, server 동시 설치
# server/.env 파일 설정
# server/google-credentials.json 배치
```

### 5.2 개발 서버 실행
```bash
npm run dev                    # client + server 동시 실행
npm run client:dev             # Vite (localhost:5173)
npm run server:dev             # Express (localhost:5050)
```

### 5.3 데이터베이스 관리
```bash
npm run db:push                # 스키마를 Railway DB에 직접 푸시
npm run db:generate            # 마이그레이션 SQL 생성
# 또는 server/ 디렉토리에서:
npx drizzle-kit push --config=./drizzle.config.ts
```

### 5.4 DB 스크립트 실행 (직접 DB 조작)
```bash
# server/ 디렉토리에서:
npx tsx scripts/파일명.ts
```
> 스크립트 작성 템플릿은 GEMINI.md의 "DB 접근 규칙" 참조
