# 시장조사 영업관리 시스템 Design

## 데이터 모델

- `market_research_runs`: 조사 조건, 실행자, 상태, 결과 통계, 오류 로그.
- `market_research_items`: 업체 원본 정보와 정밀 조사 항목.
- `market_research_change_logs`: 재조사 시 변경 필드, 이전값, 신규값.
- `sales_leads`: 관리자가 선택한 영업대상 업체와 영업상태.
- `sales_activities`: 전화, 메일, SNS, 방문, 미팅, 피드백 이력.
- `sales_materials`: 영업자료 파일/링크/템플릿.
- `sales_messages`: 발송 대상, 본문, 첨부자료, 메일 발송 결과, 차단 사유.

## API

- `POST /api/market-research/runs`: 시장조사 실행 생성. 외부 API 키가 없을 때도 데모/수동 입력 가능한 결과 구조를 만든다.
- `GET /api/market-research/items`: 조사 결과 목록. 지역/분류/운영상태/현황/영업선택 필터 지원.
- `PATCH /api/market-research/items/:id`: 조사 항목 수동 보정.
- `POST /api/market-research/items/:id/select`: 영업선택업체 생성.
- `DELETE /api/market-research/items/:id/select`: 영업선택 해제.
- `GET /api/market-research/export`: 엑셀 다운로드.
- `GET /api/sales-leads`: 영업선택업체 목록.
- `PATCH /api/sales-leads/:id`: 영업상태, 담당자, 메모, 다음 액션 수정.
- `POST /api/sales-leads/:id/activities`: 영업활동 기록.
- `GET/POST/PATCH/DELETE /api/sales-materials`: 영업자료 관리.
- `POST /api/sales-messages/send`: 다건 메일 발송 또는 발송차단/초안 로그.

## 화면

- `MarketResearchPage`
  - 조사 실행 패널, 시장조사 결과표, 필터, 상태 아이콘, 일괄 영업선택, 엑셀 다운로드, 상세 편집 모달.
- `SalesLeadsPage`
  - 영업선택업체 필터, 영업상태 변경, 활동 타임라인, 자료 선택, 메일 발송.

## 변경감지

- 업체 매칭 키는 병원명+주소+전화번호를 우선한다.
- 기존 업체와 주요 필드가 다르면 `hasUpdates=true`, 변경 로그를 생성한다.
- 신규 업체는 `isNew=true`, 영업선택업체는 `isSelected=true`로 표시한다.
- 폐업 상태는 원본과 영업선택업체 모두에 반영하되 영업기록은 유지한다.

## 수집 원천과 신뢰도

- 공식/API: HIRA, 행정안전부 공공데이터, 보건복지부, KOSIS.
- 보강/검증필요: Google Places, 병원 홈페이지, SNS, 블로그.
- 수동입력: 자동수집 불가 항목 보정.
- 산후조리원 CSV: `MARKET_RESEARCH_DRIVE_FOLDER_ID` 폴더의 최신 CSV를 Google Drive API로 내려받아 CP949/EUC-KR 인코딩으로 파싱한다.

## 테스트

- 시장조사 실행, 결과 필터, 영업선택 저장/해제, 변경감지 표시.
- 영업상태 변경과 활동기록 저장.
- 메일 발송 설정 없음, 이메일 없음, 수신거부, 폐업 업체 차단.
- 엑셀 다운로드 파일 생성.
- 빌드와 TypeScript 검증.
